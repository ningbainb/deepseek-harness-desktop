隐私政策

官方包使用按日、按月轮换的匿名值统计产品使用；诊断只在你主动确认后导出。

最后更新：2026 年 8 月 22 日

周期匿名，不采集内容

官方包默认进行匿名产品分析

官方 Desktop 包发送固定词表的产品事件，用于统计日活、月活、国家或地区级用户数、版本采用、应用内更新、拓展坞使用和启动可靠性。开发、源码、测试和第三方重新打包版本保持断开。

Desktop 只上传由本地随机秘密按 UTC 日期和月份派生的匿名值，不上传该秘密或长期稳定安装 ID。服务端只获取国家级代码，不保存 IP，也不申请定位权限。

本地优先

你的对话、提示词、AI 回复、API 密钥、账号配置、工作区、文件、插件配置和个人偏好保存在你的设备或你自行选择的服务中。Desktop 不会为了遥测或诊断自动上传这些内容。

当你主动配置并调用模型服务、远程连接、QQ Bot 或其他第三方服务时，相关数据会按照你的操作发送给对应服务商；这些传输不属于 Desktop 产品分析或诊断导出。

诊断导出范围

导出前，Desktop 会显示内容清单并要求确认。导出的 JSON/ZIP 只包含版本、Desktop/DSH/Provider/Node/Electron/操作系统摘要、更新频道、Runtime matrix 和 patch 评估、迁移/恢复状态、Task 与 Scheduler 的有界计数、安装/签名信息，以及有界且脱敏的最近错误。

诊断包包含清单和哈希，用于检查包内容和文件完整性。它只保存到用户选择的位置，不会由 Desktop 或官网自动上传；是否随后手动分享给维护者由用户决定。

明确不收集和不导出的内容

不收集对话对话、提示词、AI 回复、会话标题、文件内容、文件名或路径
不收集凭据API Key、Token、Cookie、请求头、账号信息、密码或 SSH 私钥
不导出用户内容完整 Prompt、完整 Session History、Tool Result、项目文件或项目内容
不保留身份标识用户名、真实 Home 路径、URL 凭据或 query、机器码、硬件序列号或长期设备标识

集中脱敏会移除常见 key、token、authorization、private key、cookie、真实用户目录和 URL 凭据或查询参数。不能被安全归类的内容不会因为诊断便利而被猜测性保留。

处理方式与保留

产品分析服务保存固定事件的日聚合、每日匿名去重行和每月匿名去重行，不提供单个匿名值的行为时间线。每日匿名行保留 35 天，每月匿名行保留 13 个月，趋势聚合保留 400 天。

用户导出的诊断包留在其选择的位置；项目不会自动接收、保存或保留该包。用户如果主动提交文件到 Issue、邮件或其他渠道，应先自行核对内容，并适用该渠道的公开规则。

可靠性、安全与政策更新

产品分析失败不改变安装、更新、会话或 GitHub 下载路径。诊断导出失败不会阻止应用启动、使用、更新或退出。本页面不能被解释为允许收集上述明确排除的数据。

联系维护者

如对隐私政策或诊断边界有疑问，请通过 GitHub Issues 联系项目维护者。完整的可审查版本也保存在仓库根目录的 PRIVACY.md。
