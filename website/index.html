常见问题

关于 DeepSeek Harness Desktop

拖入文件后会自动解析成 Markdown 吗？

不会。普通文件保存到当前工作区后显示附件卡片，发送时提供真实文件引用，由模型按需调用工具读取和研究；不自动把全文注入对话。文件可添加不代表所有格式都能被模型理解，图片使用独立的压缩与视觉流程。

记忆会自动保存或发送吗？

模型建议需要你确认后才保存。开启记忆引用后，系统按本轮输入检索相关记忆，并将引用内容随请求发送给当前模型供应商；归属或作用域无法确认时不引用。可在拓展坞的个人偏好中查看和管理。

4.2 三个平台都是正式支持吗？

Windows x64 是正式版；macOS arm64 与 Linux x64 目前标记为 Preview。三个构建会进入同一个 Release，但平台权限、图形会话与系统沙箱能力并不完全一致。

DeepSeek Harness Desktop 是什么？

它是社区维护的开源桌面发行版，融合公开的官方 DSH Runtime、Web UI 与 Desktop 能力边界，并提供 Browser Use、Computer Use、插件、主题与原生生命周期。

安装时需要另外配置 Node.js 吗？

不需要。Windows x64 安装包已经包含运行所需组件，下载并安装后即可启动。

这个项目免费并且开源吗？

是。安装包可以免费下载，源代码托管在 GitHub，并采用 BSD-3-Clause 许可证。

性价比模式如何工作？

首次选择性价比模式会打开配置引导：专家主控模型负责理解、拆解、派发、复核和汇总，副模型只执行被派发的局部任务。用户可以选择更省、智能平衡或更强策略。

可以导入 Claude Code 和 Codex 项目吗？

可以。桌面版支持只读扫描 Claude Code 与 Codex 的项目和历史会话，用户预览并确认后导入 Harness 工作区；历史工具调用不会重新执行，敏感内容会先脱敏。

用量看板里的 Token 峰值可信吗？

生成速度按严格滚动 1 秒窗口统计，同毫秒流式批次先合并，usage 汇总只修正账单 Token；没有有效流式样本时不显示虚假的 TPS。

支持哪些操作系统？

Windows 10/11 x64 为正式版；macOS Apple Silicon arm64 与 Linux x64 为 Preview。

DeepSeek Harness Desktop 是官方 DeepSeek 产品吗？

不是。它是社区维护的开源桌面发行版，使用公开的官方 @deepseek-ai/dsh Runtime 与 SDK，但拥有独立应用 ID、数据目录、协议和更新源；DeepSeek Harness 与相关标识归各自权利人所有。

桌面版能和官方 Web 端同时运行吗？

可以。桌面版使用隔离的 profiles/desktop profile；首选端口被占用时会自动选择可用端口，不覆盖官方 Web 端配置。

如何验证下载的 Windows 安装包？

从同一 GitHub Release 下载 SHA256SUMS.txt 和 release-manifest.json。先比对安装包 SHA-256，再查看 manifest 记录的实际签名状态；本地或源码构建可能未签名，不能据此推断发布资产状态。
