# DeepSeek Harness Desktop 5.3.0-rc.7

## 中文

### 本次亮点

桌面对话输入框移除梁神插件的独立拨杆，恢复官方 Agent 预设菜单。原有模式和已保存的会话预设继续由官方界面管理。输入框稍晚加载或重新打开时，桌面设置仍能正常启用。Codex 模型在完成授权后出现在模型选择器，授权入口仍在设置中。

记忆管理支持按内容、标签和作用域查找条目，并区分加载失败、没有记忆与没有搜索结果。拓展坞搜索标出结果所在分组，可用键盘打开对应设置。设置重试返回原来的配置页面。

### 验证

本地验收覆盖桌面模式选择、Codex 授权状态、记忆管理和拓展坞导航。桌面内核使用官方 DSH 0.2.2-rc.3。

### 下载与校验

Windows x64 提供一个体验安装包。SHA-256 随本机构建记录提供。

### 说明

体验包用于本地验证，正式发布需要另行确认。

## English

### Highlights

The Desktop composer removes the separate Liangshen lever and restores the official Agent preset menu. Existing presets and conversation settings remain available through their original controls. Desktop settings remain available when the conversation composer loads later or is reopened. Codex models appear in model selection after authorization, with the authorization entry available in Settings.

Memory management supports searching entries by text, tag, and scope. It distinguishes a failed request from an empty memory store or a search without matching results. Extension Dock search shows the group that owns each result and supports keyboard navigation to the original destination. Retrying a settings view opens the same target.

### Verification

Local acceptance covers Desktop mode selection, Codex authorization state, memory management, and Extension Dock navigation. Desktop uses official DSH 0.2.2-rc.3.

### Download and verification

The Windows x64 evaluation build provides one installer, with a SHA-256 checksum in the local build record.

### Notice

Formal publication requires separate confirmation.
