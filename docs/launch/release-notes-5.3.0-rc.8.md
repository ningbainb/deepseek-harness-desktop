# DeepSeek Harness Desktop 5.3.0-rc.8

## 中文

### 本次亮点

设置侧栏收为六组，原有快捷入口可直接打开对应页面。插件页沿用官方的「已安装 / 发现」，拓展坞可直达创意工坊。

Windows 每用户安装把差分更新缓存放在程序目录同盘。上下文费用估算可使用安装包内的价格快照。模型设置首屏显示默认模型和连接入口，性价比模式用登录提示解释尚未连接的 bai 模型。

Windows 安装器支持解包超过传统路径长度限制的依赖文件，解包失败会在提交前恢复旧程序。中文安装路径下，插件市场可调用随包的 pnpm。

## English

### Highlights

Settings uses six groups while retaining direct links to the original settings. The official Installed and Discover tabs manage plugins. The Extension Dock opens Creative Workshop directly.

Per-user Windows installations place the differential update cache on the drive containing the program. Context insights use a bundled pricing snapshot so estimates are available offline for models in the snapshot. The supplier page shows the saved default model and connection actions up front. Value Mode explains when a bai sign-in is needed before the selected model can run.

The Windows installer extracts dependency files beyond the legacy Windows path limit and restores the previous program if extraction fails. The plugin market can launch bundled pnpm from Unicode Windows paths.

### Verification

Desktop uses official DSH 0.2.2-rc.3. The local build record contains installation, startup and plugin acceptance results.

### Download and verification

The Windows x64 evaluation build provides one installer, with a SHA-256 checksum in the local build record.

Formal publication requires separate confirmation.
