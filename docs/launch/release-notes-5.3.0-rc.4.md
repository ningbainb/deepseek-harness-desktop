### Highlights

Windows Setup stages large installation files on the selected program drive to reduce writes across drives. The upgrade transaction retains rollback of the application and preserves user data. The community workshop provides clearer status and browsing when its upstream catalog is unreachable. Already installed plugins remain manageable. Desktop conversations hide the inline Liangshen and Standard preset switch. Official Agent Preset settings continue to manage defaults, and existing conversations retain their presets.

The Windows evaluation build records its local packaging and targeted verification evidence. The desktop uses official DSH 0.2.2-rc.3.
