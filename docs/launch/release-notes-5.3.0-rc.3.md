# DeepSeek Harness Desktop 5.3.0-rc.3

## 中文

### 本次亮点

模型高级、智能操控、任务看板和 SSH 远程开发统一从拓展坞打开。新会话使用官方 Agent 预设选择器，已有会话继续显示自己的预设。飞书试点采用可按需安装的社区即时通讯插件，现有 QQ 机器人绑定继续由桌面管理。

候选版使用官方 DSH 0.2.2-rc.3。Windows 使用随包的原生 Office 引擎提供文档预览、转换和工作簿重算。已启用的共享浏览器在覆盖安装替换程序前完成资源准备。新安装可选择数据目录，覆盖安装沿用旧 Home 和现有配置。

### 验证

版本证据随体验包记录。Windows 检查安装、旧会话续聊和回退，macOS 和 Linux 使用各自的原生预览工作流。飞书真实账号验收独立记录。

### 下载与校验

体验包的版本、提交、文件名和 SHA-256 以对应的构建证据为准。

### 说明

体验时请使用独立数据。正式发布和 NPM 发布需要另行确认。项目经验插件保留原配置与数据，首次启用仍受用户隔离验收约束。

## English

### Highlights

Advanced model settings, desktop controls, the task board, and SSH remote development are available through the extension dock. New sessions use the official agent preset selector. Existing sessions show the preset they already use. The Feishu pilot uses an optional community messaging plugin. Desktop continues to manage existing QQ bot bindings.

This candidate uses official DSH 0.2.2-rc.3. Windows includes the native Office engine for document preview, conversion, and workbook recalculation. When the shared browser is enabled, the installer prepares its resources before replacing the program. Upgrades retain the existing home and settings.

### Verification

Windows installation, session continuation, and rollback have separate evidence. The macOS and Linux previews use their respective native runners. Live Feishu account verification is tracked separately.

### Download and verification

The candidate build evidence records the version, commit, artifact filename, and SHA-256 for each platform.

### Notice

Evaluate the candidate with isolated data. Formal releases and NPM publication require separate confirmation. Project experience activation remains subject to user isolation verification, with existing configuration and data preserved.
