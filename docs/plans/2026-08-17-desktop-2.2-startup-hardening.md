# Desktop 2.2 Startup Hardening Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Release Desktop 2.2.0 with invisible Windows terminal processes, attributed upgrade cleanup, safe legacy plugin migration, stable restart ports, and evidence-based plugin isolation.

**Architecture:** Wrap the Windows DSH runtime in a hidden Windows PowerShell process so descendants inherit a hidden console, while retaining per-spawn hiding as defense in depth. Add an allowlisted, exact-name-and-version migration before the generic unmanaged-package guard, leaving every other collision protected.

**Tech Stack:** Electron, Node.js ESM, Windows PowerShell, node:test, pnpm, electron-builder.
