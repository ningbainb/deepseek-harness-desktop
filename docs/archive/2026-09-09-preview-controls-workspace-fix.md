# 预览控件与工作区入口修复

## 问题与实现

用户反馈浏览器/文件预览右上角控件重叠、偶尔消失，首页选择工作区仍使用旧流程。

- 文件面板关闭按钮使用绝对定位，叠加标题栏高度；同时另一套工作台将两枚开关固定在同一区域。关闭按钮改为工具栏内的正常布局，文件栏和右侧独占的预览栏为并存按钮预留 84 像素。
- 布局与 React 挂载逻辑只查找一次页面容器。应用框架替换或注入列被移除时，重新绑定布局并挂载面板；卸载时清理 React 根与订阅，恢复原框架列，保留面板 store。
- 首次实现只覆盖侧栏添加项目，漏掉首页“选择工作区”。首页与侧栏接入相同居中表单；首页列出已有项目，打开已有项目不创建重复工作区、不重命名项目。

所有修改均位于自有插件；没有修改官方 DSH 源码、SDK 或第三方侧栏源码。原有侧栏开关、文件关闭、预览关闭和展开入口均保留。
