# Desktop 5.2.0 offline runtime deduplication implementation plan

> Implementation: execute inline with focused red/green tests and an independent final review. The user's request to optimize follows the measured offline reconstruction proposal; proceed without repeating approval questions.

**Goal:** reduce the actual unsigned Windows Setup size while retaining the complete offline generic Electron runtime, application features, installer transaction and update behavior.

**Design:** keep the verified `win-unpacked` directory complete for normal use. Immediately before NSIS compression, create a hash-bound reconstruction manifest and a small PE literal payload, temporarily withhold only verified Electron duplicates into a separate staging directory, and restore the original files in `finally`. Identical resources are copied from the application root during installation. Matching PE sections are reused to reconstruct the original independent `electron.exe`; the result must match the original whole-file SHA-256. No official DSH source, installed SDK source or dependency patch is changed.

**Scope:** Windows x64 installer only. Do not change Electron startup semantics, plugin requirements, offline operation, NSIS differential archive settings, signing policy or user profiles. macOS/Linux retain the existing path and require their native CI before any cross-platform claim. Current validated 440488759-byte Setup must be copied and hash-verified before any build that replaces `dist`. No commit, push or publication is part of this task.

**Evidence:** `E:/DeepSeekHarnessDesktop-Build/artifacts/desktop-5.2.0-performance-20261027/size-followup/size-attribution.json` and `pe-reuse-spike/result.json`. The measured opportunity is 101593244 compressed bytes; this is not a rebuilt installer measurement.

## Review focus

- Failed restoration must stop installation before transaction commit and preserve old application/user data.
- New installation must restore files even when no previous transaction journal exists.
- Tampered source, literals, manifest ranges, traversal paths, links and target files must fail without writing outside the installation.
- Compression failures must put all withheld files back; no hard links, downloads or first-launch reconstruction.
- New Setup extraction must reconstruct the same bytes as the verified full directory; source-only checks cannot establish installer acceptance.
