## Implementation

Seventeen byte-identical Electron resources are copied from the application root during installation. The original independent `electron.exe` is reconstructed from matching Desktop executable sections plus 100864 literal bytes; complete SHA-256 must match the original. There is no executable shim, runtime download, hard link or feature removal. Official DSH source and installed SDK source remain untouched.

The manifest digest is bound through trusted installer defines. Reconstruction runs after extraction and before registration/shortcuts, enforced by a compiler sentinel. Fresh installs also journal their transaction. Corrupt sources/literals/manifests, invalid ranges, linked paths and mismatching existing targets stop installation; the existing rollback preserves the old application and external user Home.

The stock electron-builder main script, uninstaller generation, signing policy, size checks, nonsolid differential archive and blockmap remain active. A pinned, hash-checked stock core include adds the early hook. Only the exact generated NSIS cache is invalidated; archive readability and omitted targets are checked before assembly. Default full builds are retained. Explicit installer-only reuse verifies current code, runtime metadata, ordered exports/imports and declared assets.
