# 3.5.0 安装中止排查与加固

## 本机观察与结论边界

- 3.5.0-beta.2 安装窗口停留在“安装已中止”，隐藏的详情列表也是空的。
- 旧版主程序和 app.asar 仍存在；运行日志记录了正常退出和安全关机回执。
- 检查时没有持续文件占用，也未发现重复的不同安装位置注册。
- 旧安装器没有持久化失败阶段和脚本输出，因此无法倒推这次中止的唯一原因。
- 没有手动卸载、删除或清理用户的真实安装、注册信息、会话或升级备份。

## 加固内容

1. 目录备份遇到 Windows 共享占用错误 32/33 时，最多等待 5 秒重试。权限或未知错误直接报告；持续占用仍停止并恢复，不强行替换。
2. 注册信息清理错误不再静默忽略，避免未成功准备的旧版卸载器被继续调用。
3. 使用 electron-builder 的正式卸载检查扩展点，旧卸载器异常时以 Abort 进入恢复回调，而不是 Quit 直接退出。
4. 每次安装单独保存本地 UTF-16LE 日志：`%TEMP%\dsh-desktop-install-<pid>-<tick>.log`。记录准备、提交、卸载异常、恢复等阶段和错误码，安装失败后显示日志路径。
5. 日志写入失败不影响安装。日志不读取会话或凭据，也不自动上传，但错误文本可能包含本机路径，分享前应检查。

## 验证

- 编译并运行生产 NSIS 宏的隔离小型安装器：新装、覆盖、提交失败、安装阶段中止、旧卸载器退出异常、旧卸载器启动失败、残留注册信息、日志不可写、预检文件持续占用，共 9 个场景通过。
- 安装专项 Node 测试 19 项通过，含真实 Windows 目录句柄占用、旧文件和注册信息恢复、保留备份隔离、测试机保护。
- 功能基线通过。桌面核心回归首轮在记忆页点击出现元素脱离 DOM 超时；未降低断言，重跑 17/17 套件通过（576.3 秒，最后一组含 132 项测试）。首次失败日志保留，不将其归因于已确认的安装故障。
- 本地验证记录：`.tmp/installer-focused.log`、`.tmp/installer-abort-lifecycle-verified.log`、`.tmp/installer-core-regression.log`、`.tmp/installer-core-regression-retry.log`、`.tmp/installer-fix-payload-verification.log`。
- 这些是隔离测试，不等同于用户完整安装器的真实覆盖升级验收，也不能证明本次中止一定由目录占用造成。
