# 3.5.0 主界面面板入口整理

## 范围

- 主界面保留原生右侧栏开关；空白会话继续使用原生侧栏返回入口。
- 插件底部面板、兼容侧栏的独立常驻按钮收进“工具 / Tools”菜单的“布局 / Layout”分组。
- 菜单显示展开状态，支持键盘方向键、Home、End、Escape。
- 调用原按钮的既有事件，不重建面板，不删除终端、任务、编辑器或标签页；不变更已有用户配置。
- 只有识别到原生入口及完整兼容按钮组时才转移入口；未知结构、多实例、缺失菜单、原生能力消失时保留或恢复原按钮。
- 对话流式文本不触发全页面板查询。

## 同时修复

实机验证发现，侧栏插件仍依赖旧版 `[data-slot="conversation"]` 定位底部面板。DSH 0.1.5 的空白会话没有该节点，导致状态已展开但面板宽度为零。

更新社区 `dsh-better-sidebar@0.14.0` 的现有补丁：优先使用与其布局 CSS 一致的当前 frame / conversation 标记，保留旧版定位回退。源码及两份发布 bundle 同步；未修改官方源码 checkout，未升级 SDK。
