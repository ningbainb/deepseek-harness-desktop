# Desktop 3.3.0 发布准备

日期：2026-09-09。起点：本地与远端 main 均为 `361b81c`，目标仓库为 `https://github.com/ningbainb/deepseek-harness-desktop.git`。本记录描述发布准备；实际发布结果以 `desktop-v3.3.0` 对应的 GitHub Actions 运行和 Release 资产为准。

## 范围

收录已完成的拓展坞设置、项目与工作区弹窗、文件附件交付、预览控件、记忆活动，以及 [3.3.0 埋点第一阶段](2026-09-09-release-330-analytics-plan.md)。更新双语发布说明和变更日志，使普通文件的描述与按需读取实现一致。工作区临时日志、截图、测试数据库及本机配置不作为产品源码发布。

## 发布门禁修复

上一轮 main 的 CI 在 SDK 导入基线和 Known Good 运行时清单检查中失败。逐项核对后，同步 15 个精确导入签名：10 个属于已有官方 SDK 测试夹具（滚动、工作区迁移和手动压缩测试），5 个属于新增界面组件的 type-only SDK 引用。没有放宽全局导入规则、改变允许目录或删除断言。全部 SDK 来自 NPM 包，官方源码 checkout 没有写入。

运行时清单重建纳入当前锁文件哈希和实际使用的 root slot，同步派生支持矩阵与耦合审计。运行时包版本、能力要求及兼容补丁保持原有约束。临时目录 `.tmp/` 加入 Git 忽略，避免验证产物进入提交。

## 交付约束

正式构建使用仓库变量配置的 Cloudflare HTTPS 事件端点，随安装包写入 officialBuild 标记；源码默认配置仍为空端点。此前本地构建的 3.3.0 安装包早于埋点改动，不能作为本次发布资产。正式发布必须从本次提交重新构建，通过仓库验证和打包回归后，生成安装包、blockmap、latest.yml、SHA256SUMS.txt 与 release-manifest.json；不在本次操作中发布 NPM 包。
