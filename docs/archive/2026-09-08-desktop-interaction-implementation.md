## 用户可感知的变化

| 项目 | 实现行为 |
| --- | --- |
| 性价比模式 | 预设名称与简介中文化，设置中的功能标题、主控与执行模型名称去掉重复英文括注；供应商与模型标识保持真实名称 |
| 拓展坞和设置拖动 | 设置拖动使用帧合并与 transform，结束时保存位置；原生拓展坞拖动/缩放期间暂停粒子循环，停止后恢复；相同 WebContentsView 尺寸不重复提交 |
| 浏览器 | 预览地址栏右侧提供常驻关闭按钮，调用原有标签页关闭流程，恢复输入焦点；兼容侧栏浏览器入口也委托原有关闭动作 |
| 创建项目 | 居中弹窗、名称输入、系统文件夹选择、自动命名、改名保护、目录重复检查、失败重试；创建后进入实际项目会话；浏览器宿主保留原目录浏览流程 |
| 文件附件 | 通用文件分批串行上传，显示添加中/成功/失败，支持重试与移除；真实工作区引用写入原草稿，处理过程中阻止提前发送；图片保留原有原生附件及压缩流程 |
| 异常反馈 | 重复文件提示、失效引用提示重新添加、超限提示；文件夹拖入提示通过创建项目添加 |
| 视觉 | 使用现有主题变量；项目弹窗适配深浅主题、窗口缩放；附件区域避开粒子画布 |

## 数据与行为边界

普通文件采用真实文件引用，代表模型可以按需读取，不代表所有格式都已解析。单个通用附件上限 100 MB，超限单独失败，不拖累同批成功项。源文件不被修改，上传副本保存在当前工作区 .dsh-attachments 下；可能出现在文件树或 Git 未跟踪列表，不自动修改忽略规则。移除附件只移除草稿引用，副本保留以免破坏历史消息。

文件权限由已有宿主会话与已登记工作区校验，拒绝跨源请求、未知会话、路径穿越与指向工作区外的链接。切换会话不会把仍在处理的文件插入其他会话；已持久化草稿中的附件引用会在恢复时检查。重启恢复依赖官方草稿持久化能力，没有新增独立草稿数据库。非桌面宿主若缺少原生文件路径能力，不能保证跨两次文件选择去重，只能按 File 对象身份识别。

关闭网页不会更改其登录数据。Ctrl+W 在浏览器地址栏内生效；跨源 iframe 自身的键盘事件不向父页面传播，始终可使用地址栏关闭按钮。

## 拖动测量

环境：Windows x64，Electron 43.4.0，显示缩放系数 1，隔离测试 Profile。对设置窗口同一帧连续派发 120 次指针移动事件：布局尺寸读取 1 次、位置样式写入 1 次；pointercancel 后拖动态释放。原生窗口的 100 次移动通知在单元测试中仅发布开始/结束两个事件。

这些是本次合帧与资源恢复机制的测量，不是 GPU 帧率，也不是修改前后的实际 FPS 对比。尚未完成所有显卡、刷新率与多显示器组合下的帧率测量，不声明稳定 60 FPS。

## 建议用户测试

1. 打开性价比模式，核对简介与模型设置文案。
2. 打开拓展坞，连续拖动、缩放、松手；切换页面后重复操作。
3. 创建项目，点击源文件夹选择目录；取消一次后重选，检查项目名、成功进入与重复项目提示。
4. 拖入文本、PDF、Office、压缩包及未知扩展名文件，查看卡片和草稿；删除一项、处理期间切换会话、失败后重试。
5. 在预览面板新建 URL 预览，使用地址栏右侧关闭按钮；确认输入草稿保留。
6. 在深浅主题和常用系统缩放比例下检查弹窗与附件文字。
