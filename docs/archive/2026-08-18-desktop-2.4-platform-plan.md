# Desktop 2.4 Reliability Platform Implementation Plan

> Implementation record for the current worktree. No commits, pushes, or releases are part of this plan.

**Goal:** Deliver deterministic update shutdown, renderer-surface IPC boundaries, Desktop Contract v1, and profile-scoped Task Board host persistence without replacing Electron or the official DSH runtime.

**Architecture:** Keep Electron as a lifecycle/security shell and keep every privileged operation behind an explicit IPC or loopback-only Host route. Add small modules for shutdown receipts, surface identity, and contract snapshots; extend the existing TaskStore seam with a Host file store plus a migration/fallback client rather than replacing the board state machine.

**Tech stack:** Electron, Node.js 24, NSIS/PowerShell, Cordis Host bundles, official DSH rc.6 SDK packages, TypeScript, node:test, Vitest, Playwright.
