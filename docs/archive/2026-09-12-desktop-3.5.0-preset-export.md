# Desktop 3.5.0 Preset 导出修复记录

本次改动基于 `main` 的 `713eda02f078d02bda97f1e6493b0ac52da0fd0e`，预留给 3.5.0；未更改版本号、3.4.0 标签或已发布安装包，未执行发布。

## 定位与改动

- 托管 Desktop Profile 通过应用内置包链接构建，正常情况下没有 `pnpm-lock.yaml`。导出只在存在社区插件时要求该锁文件；无社区插件时可离线导出。
- 自带 `@linxin666/dsh-desktop-repair` 不作为社区插件写入预设。不改变该组件的安装、启用、修复入口或其他插件保护规则。
- 社区插件仍要求实际安装的精确版本和锁文件里的 SHA-512，不联网猜测、不自动安装、不静默忽略缺少校验信息的插件。插件清单读取加入现有串行队列，防止与安装事务交错。
- 修复通知缺少 `.toast` 样式类导致被窗口裁剪的问题，增加小窗口边界和长文本换行。
- 环境预设页持续保留导出状态：等待保存、成功、取消或失败。导出期间禁止重复操作，失败后可以重试；中文解释与可展开技术详情并存。
- 保存窗口的标题、文件类型和确认按钮使用中文。Preset 的格式、隐私过滤、完整性验证和原子替换行为保持不变。

## 验证

- 先新增真实 `ensureDesktopProfile` + `PluginManager` + `PresetService` 回归用例，确认旧实现因缺少锁文件失败，再修复实现使其通过。
- 77 项相关测试通过，覆盖实际托管 Profile 导出及预览、社区插件精确版本与完整性、旧文件保全、IPC 边界、操作队列及错误中文说明。
- 对维护者现有 Profile 仅执行只读插件清单导出检查，6 ms 返回 0 个社区插件，不运行安装命令、不联网、不修改本机 Profile。
- 新增 `verify-preset-export.mjs`，纳入 Desktop 核心回归和机器可读功能基线。使用隔离用户目录、实际应用窗口及完整导出链路，仅替换系统文件选择器；覆盖中文路径、实际文件校验、可见通知、取消保全、真实文件系统错误与重试。
- 上述独立导出 E2E 已通过，包括 680 × 480 窗口内错误通知边界，以及错误出现 5 秒后页面仍显示结果。
- 功能基线、SDK 导入边界、耦合审计、运行时清单与支持矩阵、社区插件质量报告、文档门禁及变更文件 emoji 检查通过。
- 完整核心回归实际执行到第 9/17 组：前 8 组通过，第 9 组 `Long Conversation Scroll & Turn Navigation` 的启动引导 `dismissStartup` 点击“继续”时元素脱离 DOM，等待 30 秒后超时。日志表明 Runtime 已就绪，尚未开始对话滚动断言；未改动或跳过该测试，完整回归不能记为通过。本次新增导出 E2E 随后单独运行通过。
