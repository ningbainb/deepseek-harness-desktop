# Desktop 3.0 documentation examples

These files are copyable, non-secret fixtures for Desktop integration documentation. They are not published packages or installer artifacts.

- `desktop-plugin/` contains a minimal DSH bundle manifest with Desktop compatibility metadata.
- `desktop-preset/` contains the extracted source entries for a minimal Preset v1 archive.

Use [plugin Desktop manifests](../plugin-desktop-manifest.md) and [preset authoring](../preset-authoring.md) before adapting either fixture.
