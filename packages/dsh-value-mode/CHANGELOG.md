# Changelog

All notable changes to `@linxin666/dsh-value-mode` will be documented in this file.

## 0.2.0

### Added
- V2 session-scoped overrides supporting temporary strategy and expert model tuning without altering global configurations.
- Real-time token analytics and estimated cost savings ratio displayed in the session header status popover.
- Intelligent escalation and auto-review triggers for consecutive failures and high-risk module modifications (security, migrations, updaters).
- Expandable expert consultation history drawer tracking summaries and call durations.

## 0.1.0

### Added
- Initial release of Value Mode (性价比模式) DSH plugin.
- Support for primary executor model and secondary expert consultant model.
- Three operating strategies: Saver, Balanced, and Powerful.
- `consult_expert` DSH tool with strict bounding and recursion guardrails.
- Web UI settings card, session header chip, and composer manual trigger button.
