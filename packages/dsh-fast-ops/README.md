# dsh-fast-ops

English | [中文](README.zh.md)

## What it does

Provides token-efficient batch file reading (`fast_read_files`), unified workspace search (`fast_search`), SHA-256 CAS multi-edit (`fast_edit_batch`), progressive specialized tool discovery (`fast_discover`), RFC-4180 table reading, and bounded session result caching (`fast_result`).

Architectural design creatively adapted from [`T-Auto/dsh-ops`](https://github.com/T-Auto/dsh-ops) (MIT License) for native integration in DeepSeek Harness Community Desktop without shipping redundant shell payloads.
