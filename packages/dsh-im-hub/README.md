# dsh-im-hub

English | [中文](README.zh.md)

## What it does

Provides a lightweight, zero-native-dependency 4-channel domestic IM gateway (**Feishu WebSocket**, **DingTalk Stream**, **WeCom Webhook & App Callback**, and **Generic HMAC Webhook**) with a unified semantic core, per-conversation serialization, slash commands (`/new`, `/stop`, `/status`, `/workspace`, `/approve`, `/reject`, `/help`), and dual-side tool approval sync alongside built-in `@tencent-connect/dsh-qqbot`.
