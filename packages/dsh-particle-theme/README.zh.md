# dsh-particle-theme

[English](README.md) | 中文

面向 DeepSeek Harness Web UI 的独立全页粒子主题。它把 Desktop 启动页的粒子鲸鱼延伸到工作界面，同时不替换用户正在使用的皮肤。

## 能力

浏览器客户端会在交互界面下方挂载一张固定且不接收指针事件的画布，并渲染内置 `whale` 场景。鲸鱼会漂游、呼吸和摆尾，稀疏环境粒子在亮色与暗色模式中保持内容对比度。

控制器会自动选择页面档位：

| 页面状态 | 行为 |
| --- | --- |
| 普通 | 使用配置的密度、透明度和速度 |
| 可编辑控件聚焦 | 降低密度、透明度和速度 |
| 弹窗打开 | 比聚焦状态更安静 |
| 减少动态效果 | 仅显示稀疏静态画面 |
| 页面隐藏 | 停止并清空渲染 |

## 安装

DeepSeek Harness Desktop 通过 `@linxin666/dsh-web-ui-all` 自动挂载这个 bundle。其他 DSH profile 可把本包作为普通 bundle 依赖加入并包含其 patch。

## 配置

`particle-theme` 设置命名空间显示在「设置 > 插件配置 > 粒子主题」。

| 字段 | 默认值 | 有效范围 | 用途 |
| --- | ---: | ---: | --- |
| `enabled` | `true` | — | 挂载或移除全页画布 |
| `theme` | `whale` | `whale` | 选择已注册场景 |
| `density` | `1` | `0.35`–`1.5` | 缩放粒子数量 |
| `opacity` | `0.26` | `0.08`–`0.55` | 缩放场景透明度 |
| `speed` | `1` | `0.4`–`1.6` | 缩放运动速度 |

修改会通过标准 settings scope 发布并即时生效。关闭主题会立即移除画布。

## 性能与无障碍

渲染只使用一个动画循环，限制粒子数量，并把设备像素比上限设为 1.5；持续帧耗时反馈会在慢帧时逐步降低质量，在稳定快帧时恢复质量。页面隐藏后循环暂停；偏好减少动态效果的用户只获得低密度静态画面；画布不会拦截指针或无障碍输入。

桌面窗口拖动和缩放期间暂停粒子循环，结束后恢复。即使没有附件或输入焦点，画布也会避开原生输入区；旧附件栏保留同样的保护。避让边界跟随草稿高度、滚动和重挂载，鲸鱼在边界上方布局，不穿过输入内容。系统“减少动态效果”偏好变化即时生效。

## 扩展接口

客户端导出 `ParticleThemeRegistry`、`ParticleThemeDefinition` 和页面档位基础类型。未来场景只需注册唯一 ID，并返回带有 `update(state)` 与 `dispose()` 方法的对象。页面控制器无需修改，因此新主题可以复用同一套生命周期、设置、无障碍和页面感知规则。

## 模型体验

主题只在渲染端运行，不会增加系统提示词、对话 token、工具、网络请求或模型延迟。

## 已知限制

当前随包提供的设置 schema 只接受内置 `whale` ID。新场景包除了注册定义外，还需要扩展可选主题值。自适应质量依据持续帧耗时，而不是 GPU 遥测。
