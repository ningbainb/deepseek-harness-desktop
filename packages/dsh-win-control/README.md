# dsh-win-control

English | [中文](README.zh.md)

## What it does

Integrates Windows UI Automation desktop control (`CursorTouch/Windows-MCP`) through DeepSeek Harness's native `@deepseek-ai/dsh-mcp-client` bridge, with per-session authorization, lazy tool schema reveal, domestic PyPI mirror speed probing, and live UIA/DPI diagnostics.
