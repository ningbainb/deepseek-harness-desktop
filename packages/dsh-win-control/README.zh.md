# dsh-win-control

[English](README.md) | 中文

## 能力

通过 DeepSeek Harness 原生 `@deepseek-ai/dsh-mcp-client` 桥接挂载 Windows UI Automation 桌面操控（`CursorTouch/Windows-MCP`），提供按会话隔离的授权胶囊开关、上下文按需展开工具、国内 PyPI 镜像测速一键部署以及 UIA/DPI 在线诊断。
