# 工作区检查点

- 真实工作区只允许读取快照数据，以及在用户批准的恢复事务中精确写入已审查的文件。所有 Git 写操作必须定位到应用数据目录内的隔离裸仓和专用索引。
- Git 子进程须清除继承的 `GIT_*`，使用可验证的绝对可执行文件路径与隔离配置。严禁重命名、移动或写入真实 `.git`，严禁批量清理工作区。
- 恢复需要本机所有者会话、当前工作区权限、有效预览和单次原生批准。权限复查和漂移检测必须在恢复锁内完成。恢复前的保护快照和异常补偿路径都要纳入测试。
- `src/core/protocol.ts` 是客户端唯一可直接消费的共享接口。浏览器按需加载离线差异预览，避免把渲染器和语法高亮装入聊天初始化路径。
- 集成测试使用隔离工作区及隔离本地身份，断言完整保留真实 Git 历史、受保护文件和撤销状态。
