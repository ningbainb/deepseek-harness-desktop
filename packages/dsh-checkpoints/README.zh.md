# 工作区检查点

[English](README.md) | 中文

`@ningbainb/dsh-checkpoints` 记录 Agent 对话轮次中的工作区文件变更。在发生改动的轮次底部选「查看变更」，可以并排或统一查看差异。可选择单个文件或整组变更，预览对当前工作区的影响，再在桌面确认框中批准。恢复操作在改动文件前先保存独立的撤销检查点。

桌面 Profile 通过 `cordis.patch.yml` 挂载插件，优先使用桌面已验证的随包或受管 Git，并可回退到绝对路径的系统 Git。系统 Git 需支持 SHA-256 仓库。缺少兼容 Git 时，检查点功能不可用。打开文本差异时按需加载语法高亮，渲染器加载失败时仍可使用内置文本视图。

每个已授权工作区在 `<DSH_HOME>/checkpoints/` 下拥有独立的 Git 对象库与索引。快照历史与项目的 Git 分支、提交和暂存区隔离。嵌套仓库、符号链接、依赖目录、构建目录、受保护的凭据文件及超过大小上限的文件均在快照范围之外。恢复仅触及预览中确认的路径。工作区状态变化后，需要重新预览。

检查点覆盖显式注册的桌面工作区。恢复要求本机所有者具备会话和工作区权限，工作区处于空闲状态，并在原生对话框中确认当前预览。恢复过程中，插件会在写入每个文件前重新校验权限。已批准的 MCP Apps 写操作与绑定到工作区的 ACP 提示也通过同一本地服务生成检查点。

渲染依赖、许可证和参考实现见 [第三方声明](NOTICE.md)。
