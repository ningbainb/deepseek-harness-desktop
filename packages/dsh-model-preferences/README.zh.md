# 模型偏好

[English](README.md) | 中文

本插件为官方 DeepSeek Harness 模型选择器增加持久化的模型置顶、供应商排序、供应商启用/禁用和最近使用记录。

模型目录、能力状态、推理选项、选择请求、重载和过期响应处理仍由官方 `ModelDirectory` 负责。本插件目前把偏好投影到官方“设置 → 模型”页面和 composer 模型席位；偏好卡片直接显示在官方模型页内，不再生成第二个侧边栏入口。不会放在“Web UI 插件”页面，也不会删除凭据、注销适配器、中断当前请求或修改 Host 默认模型。

本轮不纳入自定义 `/model` 命令替换，也不修改官方命令 contribution。插件只负责设置卡和 composer 模型席位中的本地偏好投影；官方 `/model` 保持原生行为，不作为本轮交付门槛。

设置命名空间为 `model-preferences`。
