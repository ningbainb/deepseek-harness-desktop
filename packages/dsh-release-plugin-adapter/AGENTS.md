# Release plugin adapter

- Vendor archives are immutable. Preserve original package and client module identifiers.
- Keep diagnostics out of the product settings panel. Navigation uses actual Desktop contracts.
- Main conversation documents default Dafeiyu on only when no visibility choice is saved. Preserve explicit off choices and suppress the widget in independent settings documents. Never change the existing pet configuration or vendor data.
- Desktop bootstrap is owned by `apps/dsh-desktop/src/browser-host-bootstrap.mjs`; keep its token, entry and relaunch checks intact.
- Full-body visibility takes temporary priority over the original pet renderer and polling. Retain the original settings card and saved choices; turning the full-body companion off returns control to those choices.
