# Chat Artifact and MCP Apps notices

[Mermaid Tiny 12.3.0](https://github.com/mermaid-js/mermaid/releases/tag/@mermaid-js/tiny@12.3.0) is an optional [MIT-licensed](https://github.com/mermaid-js/mermaid/blob/develop/LICENSE) browser runtime. Diagrams render on demand in an opaque frame using strict configuration, bounded input, a supported diagram-type list, and a closed network policy. Exported SVG retains a restricted graphics subset. The adoptable release was selected within the repository's package maturity policy.

MCP Apps interoperability follows the stable [SEP-1865 specification, 2026-01-26](https://github.com/modelcontextprotocol/ext-apps/blob/v2.1.0/specification/2026-01-26/apps.mdx). The [`@modelcontextprotocol/ext-apps` 2.1.0](https://github.com/modelcontextprotocol/ext-apps/releases/tag/v2.1.0) manifest declares MIT. Its [LICENSE](https://github.com/modelcontextprotocol/ext-apps/blob/v2.1.0/LICENSE) documents the project's Apache-2.0 transition and retained MIT contributions. Chat Artifact uses the SDK's protocol types. The browser relay and authorization logic are implemented in this package.

The MCP TypeScript Client SDK 2.2.0 provides transports and capability negotiation. Its manifest declares MIT and its license file documents the same transition to Apache-2.0. The connector uses the published DSH SDK to register model tools, check session ownership, and request one-shot approvals. [SDK release](https://github.com/modelcontextprotocol/typescript-sdk/tree/v2.2.0), [SDK license](https://github.com/modelcontextprotocol/typescript-sdk/blob/v2.2.0/LICENSE)

Two MIT-licensed DSH integrations informed the design. [sugarforever/dsh-mcp-apps at 5b44487](https://github.com/sugarforever/dsh-mcp-apps/tree/5b444876f7bfb0b99909c73fd2cc2a863f7463fe) contributed the idea of preserving a server's tool metadata through presentation. [openma-ai/dsh-mcp-apps at 320bfb5](https://github.com/openma-ai/dsh-mcp-apps/tree/320bfb575579e2feacf8d9274120cea6210e743f) contributed the idea of relaying JSON-RPC through two isolated frame levels and sharing a single MCP connection. This integration binds app interactions to the originating principal, session, and server. It defaults to an empty network policy and applies native DSH approval to tools outside the configured read-only list.

The pinned [`@deepseek-ai/dsh-mcp-client` 0.2.3-alpha.2](https://www.npmjs.com/package/@deepseek-ai/dsh-mcp-client/v/0.2.3-alpha.2) projects ordinary tools without their `_meta.ui` metadata. The app-capable connector therefore uses explicit profile configuration and owns a single connection for each configured App server's model tools and interactive UI.
