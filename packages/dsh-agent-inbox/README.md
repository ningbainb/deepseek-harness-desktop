# dsh-agent-inbox

English | [中文](README.zh.md)

## What it does

Review cross-session approvals and workspace Git changes.

## Install

Open it in DeepSeek Harness Community Desktop, where it is built in.

## Config

Use the sidebar entry to review requests and changes. Change notification preferences in plugin settings.

## Security model

Approval decisions and workspace changes are restricted to the local desktop user scope.

## Known limitations

Very large Git outputs are bounded by the Host.
