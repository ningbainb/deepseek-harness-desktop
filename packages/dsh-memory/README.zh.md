# dsh-memory

[English](README.md) | 中文

面向 DeepSeek Harness 的用户隔离本地记忆。每个 principal 使用独立的私有
JSON 文件，不写入远程数据库，注入模型前会做数量和长度限制。

模型只能搜索当前轮次的直接用户文本，或创建“待确认记忆建议”；只有设置页
显式保存或用户确认后才会持久化。明显的凭据会被拒绝，错误不会回显匹配内容。

存储和注入限制以 `src/core/schema.ts` 为准：每个 principal 最多保存 2,000 条，
每条正文最多 2,000 字符且最多 10 个标签；单次请求最多注入 5 条匹配记忆，
拼接后的记忆正文最多 2,000 字符。全局、工作区和会话记忆只有在当前 principal
及目标归属授权通过后才会解析。关闭记忆后不会生成任何模型可见的记忆上下文。

无效 JSON 会原样保留，并在源文件旁保存为 `memories.json.corrupt` 后报告存储错误；
未来版本的 schema 文件保持不动。两种情况都不会被静默替换为空文件。
