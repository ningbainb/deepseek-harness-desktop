# dsh-memory

[English](README.md) | 中文

面向 DeepSeek Harness 的用户隔离本地记忆。每个 principal 使用独立 JSON 文件，匹配内容按限额进入模型请求。

## 能力

- 个人偏好中按全部、全局、工作区或会话查看记忆，包括已过期条目；过期项不参与检索。
- 重新加载会读取本地文件。保存、删除及确认更新检查条目版本；冲突时保留编辑内容。
- 清空当前结果先确认数量，再按已审阅条目删除；其他作用域和后来新增的条目保留。
- 模型可搜索或提出建议，建议可确认为新增或更新同一作用域的已有记忆；重复建议合并，相同正文的重复保存会提示。
- 会话标题栏及记忆页提供最近准备的记忆上下文、匹配原因、编辑、删除和本会话忽略；关闭面板不丢弃面板内编辑草稿。

## 安装

通过桌面聚合配置或本包 `cordis.patch.yml` 挂载，依赖官方 NPM SDK 与 `dsh-user-scope`。不修改官方运行时源码。

## 配置

`memory` 设置包含 `version: 1` 和 `enabled`，默认关闭。全局、工作区、会话条目分别限定生效目标。限制以 [schema](src/core/schema.ts) 为准：每用户最多 2,000 条、每条正文最多 2,000 字符和 10 个标签；自动注入最多 5 条、正文合计最多 2,000 字符。

## 安全模型

模型搜索只使用当前轮直接用户文本；空查询不读取记忆。正文词组和标签用于排序，相关度优先，同分时考虑作用域、置顶及更新时间。管理查询与模型检索分离，所有条目均检查当前用户和目标权限。

待确认建议只在进程内存中，确认前不写入记忆文件，重启后消失。明显凭据被拒绝；内容不写入日志、遥测或诊断。上下文记录只暂存条目 ID、版本和匹配原因，读取时再次授权；不记录用户查询文本。

文件锁与原子写入保护本地 JSON。无效 JSON 保留原文件并尝试创建 `.corrupt` 备份；未来版本保持不动。缓存最长约 10 秒后重新加载；过期缓存等待加载时不参与注入。手动刷新失败也不会继续使用旧缓存。

## 已知限制

本地文件未做应用层加密；被选中的正文会发送给当前模型供应商。上下文面板说明的是请求构建阶段准备的内容，不能证明模型已采纳；字符限额可能截断单条正文。没有向量检索或自动聊天总结。

会话忽略从后续检索生效，仅保留在本次进程中；最近上下文和忽略会话分别最多保留 64 个。工作区和会话目标须提供已授权 ID。旧客户端仍可使用兼容接口；新管理界面使用版本检查和明确的删除集合。
