# dsh-memory

[English](README.md) | 中文

面向 DeepSeek Harness 的用户隔离本地记忆。每个 principal 使用独立 JSON 文件，匹配内容按限额进入模型请求。

## 能力

- 个人偏好中按全部、全局、工作区或会话查看记忆，包括已过期条目；过期项不参与检索。
- 重新加载会读取本地文件。保存、删除及确认更新检查条目版本；冲突时保留编辑内容。
- 清空当前结果先确认数量，再按已审阅条目删除；其他作用域和后来新增的条目保留。
- 模型可搜索或提出建议，建议可确认为新增或更新同一作用域的已有记忆；重复建议合并，相同正文的重复保存会提示。
- 入口集中在拓展坞的个人偏好 / 记忆，主聊天页无记忆按钮。记忆页保留最近准备的上下文、匹配原因、编辑、删除和本会话忽略；折叠不丢弃面板内编辑草稿。标签、置顶和有效期按需展开。
- 打开「记忆与知识库」可查看本地索引、选择工作区来源、搜索当前主体拥有的历史会话，或从已结束的轮次生成待确认建议。

## 安装

通过桌面聚合配置或本包 `cordis.patch.yml` 挂载，依赖官方 NPM SDK 与 `dsh-user-scope`。不修改官方运行时源码。

## 配置

`memory` 设置包含 `version: 1`、`enabled` 和可选的 `suggestAfterTurns`。两个开关默认关闭。轮次建议从用户撰写的内容提取简短观察，交由用户查看。全局、工作区、会话条目分别限定生效目标。限制以 [schema](src/core/schema.ts) 为准：每用户最多 2,000 条、每条正文最多 2,000 字符和 10 个标签；自动注入最多 5 条、正文合计最多 2,000 字符。

## 安全模型

模型搜索使用当前轮的直接用户文本。空查询不读取记忆。[本地检索引擎](../dsh-local-search/README.md) 提供混合排序和命中说明。记忆 JSON 仍为权威来源，使用候选条目前会再次授权。可选的语义检索在后台准备，提示词组装可直接使用已有的词法结果。派生索引不可用时降级为纯 TypeScript BM25。

待确认建议只在进程内存中，确认前不写入记忆文件，重启后消失。明显凭据被拒绝；内容不写入日志、遥测或诊断。上下文记录只暂存条目 ID、版本和匹配原因，读取时再次授权；不记录用户查询文本。

文件锁与原子写入保护本地 JSON。无效 JSON 保留原文件并尝试创建 `.corrupt` 备份；未来版本保持不动。缓存最长约 10 秒后重新加载；过期缓存等待加载时不参与注入。手动刷新失败也不会继续使用旧缓存。

## 已知限制

本地文件未做应用层加密；被选中的正文会发送给当前模型供应商。上下文面板说明的是请求构建阶段准备的内容，字符限额可能截断单条正文。向量检索需要显式配置提供方。轮次建议使用用户直接输入，与模型建议一样需经确认。

会话忽略从后续检索生效，仅保留在本次进程中；最近上下文和忽略会话分别最多保留 64 个。工作区和会话目标须提供已授权 ID。旧客户端仍可使用兼容接口；新管理界面使用版本检查和明确的删除集合。
